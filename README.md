# 🏦 Interactive ATM Simulator in Python

Hi! This is one of my first hands-on projects built while learning Python (currently 30% through the FreeCodeCamp curriculum). 

It is an interactive, console-based script that simulates core banking operations using structured programming logic.

## 🚀 Features
- **Interactive Menu:** Allows the user to choose multiple banking actions repeatedly.
- **Balance Persistence:** The system updates and remembers the available balance after every withdrawal or deposit.
- **Transaction History:** Uses dynamic lists to track and display every action taken by the user.
- **Reset System:** Built with nested loops so the user can reset the simulator from scratch with the full starting balance.

## 🛠️ Concepts & Technologies Applied
- Variables and data types (`int`, `str`, `list`).
- Control flow with conditionals (`if`, `elif`).
- Continuous and nested loops (`while True`).
- List manipulation methods (`.append()`).
- Console data input (`input()`).
